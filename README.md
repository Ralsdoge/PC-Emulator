# About
- Simulated computer with main features of RAM with live viewing. 
- CPU that can read and execute assembly language.
- GPU that operates with the CPU and uses simulated memory to store then draw to a simulated screen.
- And more to come maybe, I'd like to improve the viewability of larger amounts of ram and add the ability to edit it live to demonstrate corruption.

## Personal Statement
I have always wanted to do something like this. I love computers and am continuously fascinated by how they work. While building one from scratch is too much for one person alone without tons of experience- I've always wanted to be able to see and mess with memory in real time to see how it affects things. But equally enticing is to be able to see how a computer works at a base level.
